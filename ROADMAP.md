# BugVault Roadmap

Future improvements to be implemented.

## UX Enhancements

- [ ] Keyboard shortcuts (N = new issue, / = focus search, Esc = close modal)
- [ ] Dark/light theme toggle
- [ ] Issue priority levels (low/medium/high/critical) with color coding
- [ ] Collapsible sidebar on mobile
- [ ] Toast notifications instead of alerts

## Organization

- [ ] Nested tags or tag categories
- [ ] Archive issues instead of delete (with restore option)
- [ ] Issue templates for common bug types
- [ ] Custom fields per project

## Productivity

- [ ] Quick add mode (minimal form, just title + project)
- [ ] Copy error message to clipboard button
- [ ] Link related issues together
- [ ] Time tracking (when was issue created vs resolved)
- [ ] Statistics dashboard (issues per project, most used tags, etc.)

## Data & Collaboration

- [ ] Cloud sync option (GitHub Gist, Firebase, or custom backend)
- [ ] Multiple vaults/workspaces
- [ ] Issue comments/notes history
- [ ] Changelog/activity log

## Search & Discovery

- [ ] Full-text search with fuzzy matching
- [ ] Search within code blocks specifically
- [ ] "Similar issues" suggestions when creating new
